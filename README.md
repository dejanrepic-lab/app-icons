# App Icons

Public icon assets for self-hosted applications and dashboards.

These files are intended for direct use in tools such as ZimaOS and Homarr.

Icons are full-bleed squares (no rounded corners or border): the launcher or dashboard applies its own shape.

## Icons

- `porodicni-budzet.svg` — Porodični budžet
- `portfolio-tracker.svg` — Portfolio Tracker
- `porodicni-unos.svg` — Porodični unos
- `vehicle-maintenance-tracker.svg` — Vehicle Maintenance Tracker
